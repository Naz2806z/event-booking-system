# Билетный сервис на Django

Этот проект представляет собой систему для бронирования билетов на мероприятия. 
Реализован на базе фреймворка Django с использованием MVT-архитектуры.

### Основные возможности:
* 🎫 Бронирование билетов: Просмотр списка мероприятий и покупка билетов.
* 💳 Система оплаты: Имитация интеграции с Kaspi.
* 🤖 ИИ-ассистент: Интегрированный помощник для ответов на вопросы пользователей.
* 🛠 Панель администратора: Удобное управление мероприятиями и бронированиями.

### Технологический стек:
* Backend: Python, Django
* Frontend: HTML, CSS (Bootstrap)
* База данных: SQLite3
